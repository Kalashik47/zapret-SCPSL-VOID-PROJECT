## Где делиться без спама

- собственные Discord/Telegram/VK-сообщества VOID PROJECT;
- сообщества игроков и владельцев SCP:SL, если правила разрешают ссылки;
- GitHub Discussions исходного Flowseal-проекта — как пользовательское решение
  для конкретной игры, с явным указанием, что это сторонняя сборка;
- описание сервера и закреплённое сообщение поддержки;
- короткое видео с демонстрацией: ошибка → запуск BAT → успешное подключение.

Не загружайте разные ZIP под одним номером версии. Для каждого изменения
создавайте новый тег и публикуйте SHA-256: пользователи должны понимать, какой
именно файл они скачали.
