# Исполняемые файлы

Готовый релиз содержит `winws.exe`, WinDivert, Cygwin и используемые бинарные
шаблоны. В исходном дереве GitHub крупные сторонние бинарники могут отсутствовать.

Для установки используйте ZIP со страницы **Releases**, а не `Code → Download ZIP`.

Происхождение и лицензии компонентов указаны в корневом `LICENSE.txt`.
