ZAPRET SCP:SL — VOID PROJECT
============================

Универсальная сборка для:
- обычных игроков SCP: Secret Laboratory;
- владельцев и администраторов выделенных серверов SCP:SL.

Сборка помогает при DPI-фильтрации исходящих соединений к центральным сервисам
SCP:SL и связанным адресам Cloudflare. Это не VPN и не прокси: внешний IP не
меняется, а подключение игроков к игровому серверу остаётся прямым.

При запуске BAT отображается баннер:
VOID PROJECT — 193.164.16.165:7777


БЫСТРЫЙ ЗАПУСК ДЛЯ ИГРОКА
-------------------------
1. Распакуйте архив в отдельную папку. Не запускайте BAT прямо из ZIP.
2. Закройте другие версии zapret, GoodbyeDPI и VPN, которые могут конфликтовать.
3. Нажмите правой кнопкой на "SCP-SL.bat" и выберите запуск от администратора.
4. Дождитесь запуска winws.exe и только после этого запустите или полностью
   перезапустите Steam и SCP:SL.
5. Если игра продолжает показывать "Подключение к центральным серверам",
   остановите winws.exe и попробуйте "SCP-SL (ALT).bat".
6. Если не помогло, выполните автоматический тест стратегий по инструкции ниже.

Основной "SCP-SL.bat" запускает профиль HARD 16. Это подтверждённый в сетевом
тесте вариант fake + md5sig. "SCP-SL (ALT).bat" запускает HARD 20 — более широкий
вариант для трафика, который winws не смог классифицировать как HTTP/TLS.


БЫСТРЫЙ ЗАПУСК ДЛЯ ВЫДЕЛЕННОГО СЕРВЕРА
--------------------------------------
1. Запустите "SCP-SL.bat" от имени администратора до запуска игрового сервера.
2. Запустите или полностью перезапустите процесс выделенного сервера SCP:SL.
3. Проверьте LocalAdmin: сервер должен авторизоваться и обновить сведения в
   центральном списке серверов.
4. Игровой порт UDP 7777 не перенаправляется. public/server_ip должен оставаться
   реальным публичным IP вашего сервера.

Для автозапуска откройте "service.bat" от имени администратора, выберите
"Install Service", а затем стратегию "SCP-SL.bat". Проверить состояние можно
через пункт "Check Status".


КАК НАЙТИ РАБОЧУЮ СТРАТЕГИЮ
---------------------------
1. Остановите другие копии winws.exe, zapret, GoodbyeDPI и VPN.
2. Запустите "service.bat" от имени администратора.
3. Выберите "Run Tests" -> "Standard tests".
4. Сначала запустите "Confirmed md5sig variants 16-24". Для полного перебора
   выберите "SCP:SL HARD profiles 1-24".
5. Тест отдельно проверит центральные узлы SCP:SL, включая api.scpslgame.com,
   servers.php, sbg1.scpslgame.com и slac.scpslgame.com.
6. После завершения ответьте Y на предложение запустить лучший профиль. Затем
   полностью перезапустите игру или выделенный сервер, чтобы новое подключение
   создавалось уже при активной стратегии.

В сборке оставлены только 24 тестовых файла:
"general (SCPSL HARD 1).bat" ... "general (SCPSL HARD 24).bat".


ЧТО ОЗНАЧАЮТ РЕЗУЛЬТАТЫ ТЕСТА
------------------------------
- OK(код) — получен HTTP-ответ. Коды 400/401/403/404 тоже подтверждают связь.
- GAMEUA — ответ получен с заголовками, похожими на UnityWebRequest.
- TLSOK — TLS-соединение установлено, но HTTP-ответ не пришёл вовремя.
- TCPTO — TCP-соединение не установлено; маршрут или IP всё ещё блокируется.
- TLSTO/TLSRST — TCP есть, но TLS завис или был сброшен DPI.
- CERT — ошибка сертификата либо TLS перехватывает антивирус/прокси.
- DNS — домен не разрешился. Стратегия DPI не исправляет ошибку DNS.
- UNSUP — установленный curl не поддерживает этот вариант проверки.

Перед каждой проверкой тест убеждается, что winws.exe действительно запущен.
Профиль с ошибкой запуска помечается STARTUP ERROR и не выбирается победителем.


НАСТРОЙКИ ПО УМОЛЧАНИЮ
----------------------
- Game Filter: enabled, TCP + UDP.
- IPSet Filter: any.
- Пустой "lists\ipset-all.txt" означает режим any.
- Полный исходный IPSet сохранён в "lists\ipset-all.txt.backup".
- Точные домены SCP:SL находятся в "lists\list-scpsl.txt".
- Точные адреса и подключённые диапазоны находятся в
  "lists\ipset-scpsl.txt".

По требованию сборки активированы общие диапазоны Cloudflare 104.26.0.0/20,
172.67.64.0/18 и 2606:4700::/36. Эти сети обслуживают не только SCP:SL, поэтому
стратегия может затронуть HTTPS-трафик других сайтов Cloudflare.

Также добавлены проверенные адреса 104.21.33.96, 172.67.189.129, 8.6.112.6,
8.47.69.6, 8.6.112.0 и 8.47.69.0, а также актуальные точные IPv4/IPv6 из
предыдущих проверок scpslgame.com.


ЕСЛИ ТЕСТ РАБОТАЕТ, А ИГРА ВСЁ ЕЩЁ НЕ ПОДКЛЮЧАЕТСЯ
---------------------------------------------------
1. Убедитесь, что во время запуска игры winws.exe остаётся активным.
2. Полностью закройте SCP:SL и Steam, запустите выбранный BAT, затем откройте их
   заново. Уже открытая игра могла сохранить старое неудачное соединение.
3. Проверьте дату и время Windows, DNS, антивирусный HTTPS-фильтр и системный
   прокси. CERT/DNS ошибки не исправляются сменой DPI-стратегии.
4. Для игрока сохраните свежий Player.log:
   %USERPROFILE%\AppData\LocalLow\Northwood\SCPSL\Player.log
5. Для выделенного сервера сохраните свежий фрагмент LocalAdmin с URL, HTTP-кодом
   и текстом исключения.
6. Приложите лог вместе с новым файлом test_results_*.txt. Результат теста без
   лога игры подтверждает только сетевой HTTP/TLS-доступ, но не авторизацию игры.

Если все профили показывают одинаковый TCPTO при работающем winws.exe, вероятно,
блокируется маршрут/IP. Zapret не создаёт новый маршрут; тогда потребуется
выборочный прокси только для *.scpslgame.com. Игровой UDP-порт и public/server_ip
при этом должны оставаться DIRECT.


ФАЙЛЫ В КОРНЕ
-------------
- SCP-SL.bat — основной универсальный запуск для игрока и сервера (HARD 16).
- SCP-SL (ALT).bat — усиленный альтернативный запуск (HARD 20).
- general (SCPSL HARD 1-24).bat — профили для ручной проверки и тестов.
- service.bat — настройки, установка службы, статус и запуск тестов.
- README SCP-SL.txt — этот файл.


ВАЖНО
------
- Запускайте только один BAT/одну копию winws.exe одновременно.
- Не добавляйте игровой порт 7777 в параметры перехвата.
- Не меняйте public/server_ip выделенного сервера на адрес VPN или прокси.
- При проблемах с DNS сначала смените DNS, например на 8.8.8.8/8.8.4.4.
- Рабочая стратегия зависит от провайдера и со временем может измениться.
