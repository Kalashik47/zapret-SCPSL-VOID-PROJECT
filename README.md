# Zapret SCP:SL — VOID PROJECT

Специализированная сборка `zapret` для **игроков** и **выделенных серверов**
SCP: Secret Laboratory. Она предназначена для случаев, когда провайдерский DPI
мешает игре подключаться к центральным сервисам `scpslgame.com` и связанным
адресам Cloudflare.

> [!IMPORTANT]
> Это не официальный проект Northwood Studios, Flowseal или Cloudflare. Сборка
> не является VPN или прокси и не меняет ваш внешний IP.

- `zapret-SCPSL-VOID-PROJECT-Linux-1.10.1.tar.gz` — Linux.

## Для кого эта сборка

- Для игрока, у которого SCP:SL зависает на сообщении о подключении к
  центральным серверам.
- Для владельца выделенного сервера, который не может авторизоваться или
  обновить данные сервера в центральном списке.
- Для проверки разных DPI-стратегий на конкретном провайдере.

## Обязательные настройки

> [!CAUTION]
> В Windows перед запуском обязательно откройте `service.bat` и убедитесь, что
> выставлены: **Game Filter — enabled (TCP and UDP)** и
> **IPSet Filter — any**. В Linux-пакете эти значения уже зафиксированы.
> Без этих параметров обход игровых и центральных соединений SCP:SL может не
> работать. После изменения настроек перезапустите стратегию, Steam и игру.

Если значения отличаются: для `Game Filter` выберите пункт 4 → `TCP and UDP`,
а пункт 5 переключайте до появления `IPSet Filter [any]`.

## Быстрый запуск для игрока

1. Скачайте ZIP из раздела Releases и откройте его свойства. Если Windows
   показывает кнопку или флажок **«Разблокировать»**, примените его.
2. Распакуйте архив в отдельную папку без кириллицы и специальных символов.
3. Закройте другие копии zapret, GoodbyeDPI и конфликтующие VPN.
4. Запустите `SCP-SL.bat` **от имени администратора**.
5. После появления процесса `winws.exe` полностью перезапустите Steam и SCP:SL.
6. Если не помогло, остановите `winws.exe` и попробуйте `SCP-SL (ALT).bat`.

## Быстрый запуск для выделенного сервера

1. Запустите `SCP-SL.bat` от имени администратора до старта игрового сервера.
2. Полностью перезапустите процесс SCP:SL Dedicated Server.
3. Проверьте LocalAdmin: авторизация и обновление сведений в центральном списке
   должны проходить без сетевой ошибки.
4. Не направляйте игровой UDP-порт через прокси. `public/server_ip` должен
   оставаться реальным публичным IP сервера.

## Быстрый запуск в Linux

Linux-пакет использует актуальную ветку
[bol-van/zapret2](https://github.com/bol-van/zapret2), а не устаревшую первую
версию `zapret`. Он предназначен для обычного Linux с NFQUEUE и не рассчитан на
WSL или macOS.

```bash
tar -xzf zapret-SCPSL-VOID-PROJECT-Linux-1.10.1.tar.gz
cd zapret-SCPSL-VOID-PROJECT-Linux-1.10.1
chmod +x SCP-SL-Linux.sh
sudo ./SCP-SL-Linux.sh install
./SCP-SL-Linux.sh test
```

Установщик скачивает официальный архив `zapret2`, сверяет его SHA-256 по
официальному файлу контрольных сумм, запускает официальный установщик и только
после этого добавляет профиль SCP:SL. Подробности и команды отката находятся в
[`linux/README.md`](linux/README.md).

## Автоматический подбор стратегии

Откройте `service.bat` от имени администратора:

1. `Run Tests` → `Standard tests`.
2. Сначала выберите `Confirmed md5sig variants 16-24`.
3. Если результата нет — `All SCP:SL HARD profiles 1-24`.
4. В конце ответьте `Y`, чтобы сразу оставить лучший профиль активным.
5. Полностью перезапустите игру или выделенный сервер.

Тест проверяет центральные узлы SCP:SL, включая `api.scpslgame.com`, путь
`servers.php`, `sbg1.scpslgame.com` и `slac.scpslgame.com`. Успешный HTTP/TLS-
тест подтверждает сетевой доступ, но не гарантирует успешную авторизацию самой
игры. Если тест зелёный, а игра всё ещё подключается бесконечно, приложите к
обращению `test_results_*.txt` и свежий лог:

- игрок: `%USERPROFILE%\AppData\LocalLow\Northwood\SCPSL\Player.log`;
- сервер: фрагмент LocalAdmin с URL, HTTP-кодом и текстом исключения.

## Настройки по умолчанию

> [!IMPORTANT]
> Для этой сборки должны быть установлены **Game Filter: enabled (TCP and UDP)**
> и **IPSet Filter: any**. В Linux этим настройкам соответствуют включённые
> `NFQWS2_PORTS_TCP` + `NFQWS2_PORTS_UDP` и `MODE_FILTER=none`.

- `Game Filter`: **enabled (TCP and UDP)**.
- `IPSet Filter`: **any**.
- пустой `lists/ipset-all.txt` означает режим `any`;
- полный исходный список сохранён в `lists/ipset-all.txt.backup`.

В `lists/ipset-scpsl.txt` добавлены домены, точные IPv4/IPv6 и используемые
сборкой диапазоны Cloudflare. Общие сети `104.26.0.0/20`, `172.67.64.0/18` и
`2606:4700::/36` обслуживают много несвязанных сайтов. Из-за этого режимы с
широкой фильтрацией могут влиять на другой HTTPS-трафик.

## Важные замечания

- Запускайте только одну стратегию и одну копию `winws.exe` одновременно.
- Не запускайте BAT прямо из ZIP.
- WinDivert перехватывает сетевой трафик и может определяться антивирусом как
  `RiskTool`/PUA. Проверяйте источник и контрольную сумму скачанного релиза.
- `TCPTO` у всех профилей может означать блокировку маршрута/IP. Zapret не
  создаёт новый маршрут; в таком случае может потребоваться выборочный прокси
  только для `*.scpslgame.com`.
- Рабочая стратегия зависит от провайдера и может со временем измениться.
