# История изменений

## 1.10.1 — VOID PROJECT

- Сборка переименована из варианта для dedicated server в универсальную для
  игроков и выделенных серверов.
- Добавлены понятные точки входа `SCP-SL.bat` и `SCP-SL (ALT).bat`.
- Основной профиль переключён на подтверждённый HARD 16; ALT использует HARD 20.
- Оставлены только специализированные профили `SCPSL HARD 1-24`.
- По умолчанию включены Game Filter TCP+UDP и IPSet `any`.
- Расширены доменные и IP-списки SCP:SL, включая используемые диапазоны Cloudflare.
- Усилены тесты подключения к центральным сервисам SCP:SL и Unity-подобные запросы.
- Добавлен запуск найденного профиля сразу после теста.
- Добавлен баннер VOID PROJECT во все стратегии.
- Исправлена установка коротких SCP:SL BAT-профилей через `service.bat`.
- Добавлены README для GitHub и подробная офлайн-инструкция.
- Добавлен отдельный Linux-пакет на основе официальной `zapret2`: установка с
  проверкой SHA-256, профиль TCP+UDP, `MODE_FILTER=none` (`IPSet any`), тест
  центральных сервисов и безопасное отключение профиля.
